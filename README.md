# VaultX - 本地密码管理器

一款安全、本地、跨平台的密码管理器，类似 Enpass。

## 功能特性

### 数据类型
- 🔐 **登录密码** - 网站、应用账号密码
- 💳 **银行卡** - 银行卡信息、CVV、有效期
- 🔑 **API密钥** - 各种API Key、Secret
- 👤 **个人信息** - 身份证、护照、驾照等
- 📝 **安全笔记** - 加密存储私密笔记
- 🌐 **WiFi密码** - WiFi网络信息

### 安全特性
- **AES-256 加密** - 军用级加密算法
- **PBKDF2 密钥派生** - 60万次迭代，防止暴力破解
- **主密码** - 单一密码保护所有数据
- **本地存储** - 数据完全本地化，无网络传输
- **自动锁定** - 可设置空闲自动锁定

### 功能
- ✅ 密码生成器 - 可自定义长度和字符类型
- ✅ 密码强度检测 - 实时评估密码安全性
- ✅ 搜索过滤 - 快速查找条目
- ✅ 分类管理 - 多种预设分类
- ✅ 收藏功能 - 常用条目置顶
- ✅ 导入/导出 - 加密备份与恢复
- ✅ 剪贴板自动清除 - 复制后自动清理

## 技术栈

- Python 3.12+
- Tkinter (GUI)
- cryptography (加密)
- pyinstaller (打包)

## 开发

```bash
# 安装依赖
pip install -r requirements.txt

# 运行
python vaultx.py

# 打包
pyinstaller vaultx.spec
```

## 构建 EXE

```bash
pyinstaller --onefile --windowed --name "VaultX" --icon=icon.ico vaultx.py
```

## 使用

1. 首次运行设置主密码
2. 选择类型添加条目
3. 双击条目查看/编辑
4. 使用密码生成器创建强密码

## 数据存储

数据文件位置: `%USERPROFILE%\.vaultx\vault.enc`

## 安全建议

1. 设置强主密码（至少12位，包含大小写数字符号）
2. 定期导出备份并妥善保管
3. 不要遗忘主密码，无法恢复
