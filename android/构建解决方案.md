# VaultX Android APK 构建 - 完整解决方案

## ⚠️ 当前 WSL 环境问题

WSL Ubuntu 的 apt 包管理器出现问题，导致无法安装必需的构建依赖（zlib1g-dev 等）。

---

## ✅ 解决方案 1：使用 GitHub Actions（推荐）

无需本地环境，完全在云端构建。

### 步骤

1. **创建 GitHub 仓库**
   ```bash
   cd E:\CODE\VaultX
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/YOUR_USERNAME/vaultx.git
   git push -u origin main
   ```

2. **创建 GitHub Actions 工作流**
   
   创建文件: `.github/workflows/build-apk.yml`
   
   ```yaml
   name: Build APK
   
   on:
     push:
       branches: [ main ]
   
   jobs:
     build:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v3
         - name: Build APK
           run: |
             cd android
             pip install buildozer kivy cryptography cython
             buildozer android debug
         - name: Upload APK
           uses: actions/upload-artifact@v3
           with:
             name: vaultx-apk
             path: android/bin/*.apk
   ```

3. **推送并自动构建**
   ```bash
   git add .github/workflows/build-apk.yml
   git commit -m "Add GitHub Actions workflow"
   git push
   ```

4. **下载 APK**
   - 访问 GitHub 仓库的 Actions 标签
   - 找到最新的构建
   - 下载 APK 文件

## ✅ 解决方案 3：修复 WSL 环境

### 重置 WSL
```powershell
# 在 PowerShell 中运行
wsl --unregister Ubuntu
wsl --install -d ubuntu-22.04
```

然后重新运行构建脚本。

### 或者使用全新的 Ubuntu 发行版
```powershell
wsl --install -d ubuntu-24.04
```

## 📞 技术支持

如果遇到问题：

1. **GitHub Actions 构建失败**

2. **在线服务超时**

   - 分割项目

   - 重置 WSL: `wsl --unregister Ubuntu`
