# VaultX Android APK 快速构建指南

## 🚀 一键构建 (Windows + WSL)

### 方法一：使用构建脚本（推荐）

```powershell
# 在 PowerShell 中运行：
cd E:\CODE\VaultX\android
.\build_apk.bat
```

### 方法二：手动操作

```powershell
# 1. 打开 WSL Ubuntu
wsl

# 2. 在 WSL 中运行构建脚本
cd /mnt/e/CODE/VaultX/android
bash build.sh
```

---

## 📦 构建完成后

APK 文件位置：
```
\\wsl$\Ubuntu\home\<用户名>\vaultx-android\bin\vaultx-1.0.0-arm64-v8a-debug.apk
```

或者在 WSL 内：
```
~/vaultx-android/bin/
```

---

## 📱 安装到手机

### 方法一：ADB 安装
```powershell
adb install \\wsl$\Ubuntu\home\<用户名>\vaultx-android\bin\vaultx-*.apk
```

### 方法二：直接传输
1. 在 Windows 资源管理器地址栏输入：`\\wsl$\Ubuntu\home\<用户名>\vaultx-android\bin\`
2. 复制 `.apk` 文件到手机
3. 在手机上打开 APK 文件安装

---

## ❓ 常见问题

### Q: 提示 WSL 未安装
```powershell
wsl --install -d ubuntu-22.04
```
然后重启电脑。

### Q: 构建报错 "SDK not found"
```bash
# 在 WSL 中运行
buildozer android p4a
```

### Q: 提示权限错误
```bash
sudo chown -R $USER:$USER ~/vaultx-android
```

### Q: 网络问题（下载慢）
```bash
# 设置国内镜像（可选）
export GRADLE_OPTS="-Dorg.gradle.daemon=false"
```
